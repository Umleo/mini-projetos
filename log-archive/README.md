# Compactador de diretório

Um script simples em Shell (`bash`) para criar arquivos compactados tar.gz.

## Objetivo

Trabalhar com argumentos em um shell script

## Funcionalidades

- Cria um arquivo compactado em gzip

## Instalação e uso

1. Coloque o arquivo `logArchive.sh` no diretório desejado.
2. Dê permissão de execução:

```bash
chmod u+x logArchive.sh
```

3. Execute o script:

```bash
./logArchive DIRETÓRIO DESTINO(opcional)
```
