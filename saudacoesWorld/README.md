# saudacoesWord (Hello App)

## Sobre o Projeto

Este projeto consiste em uma simples aplicação que saúda o usuário em sua língua nativa com base no seu (IP). O desenvolvimento foi baseado no desafio **"Hello App"** do repositório [app-ideas](https://github.com/florinpop17/app-ideas/blob/master/Projects/1-Beginner/Hello-App.md), seguindo as regras do exercício.

## Objetivos Acadêmicos

O foco principal deste diretório foi colocar em prática conceitos fundamentais de desenvolvimento web:

- **Consumo de APIs RESTful:** Utilização da Fetch API para resgate de dados assíncronos.
- **Manipulação do DOM:** Atualização dinâmica da interface com JavaScript Puro (Vanilla JS).
- **Tratamento de Dados:** Utilização da decodificação de entidades HTML para tratar da mensagem "Hello".
- **Design Responsivo:** Estruturação inicial utilizando as utilidades de layout do Bootstrap 5.
